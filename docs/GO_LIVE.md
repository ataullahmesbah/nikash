## ধাপ ১ — একই প্রজেক্ট ব্যবহারের ৩টি সাবধানতা

একই Supabase প্রজেক্টে টেস্ট ও আসল ডেটা থাকবে, তাই:

### ১.১ রিসেট স্ক্রিপ্টটা সরিয়ে রাখুন

`database/99_reset_company_data.sql` — এটা ভুল করে চালালে ডেটা ফেরানো
যাবে না। ফাইলটা প্রজেক্ট ফোল্ডার থেকে সরিয়ে আলাদা কোথাও রাখুন, অথবা
ভেতরের `NK-1000` লেখাগুলো `NK-XXXX-CHANGE-ME` করে দিন যাতে না বদলে
চালানো সম্ভব না হয়।

### ১.২ টেস্ট কোম্পানিগুলো চিহ্নিত করুন

অ্যাডমিন প্যানেল → কোম্পানি → টেস্ট কোম্পানির নামের শেষে `(টেস্ট)`
যোগ করে দিন। পরে তালিকায় এক নজরে আলাদা করা যাবে।

### ১.৩ প্রতিদিনের ব্যাকআপ চালু আছে কিনা দেখুন

Supabase → Database → Backups। ফ্রি প্ল্যানে ৭ দিনের ব্যাকআপ থাকে।
আসল কাস্টমার আসার পর Pro প্ল্যানে ওঠাই নিরাপদ (Point-in-time recovery)।

## ধাপ ২ — ওয়েব Vercel-এ

```bash
cd nikash-web
npx vercel          # প্রথমবার — প্রজেক্ট লিংক করবে
npx vercel --prod
```

Vercel → Project → Settings → Environment Variables (Production):

| নাম | কোথা থেকে |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase → Settings → API → Project URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | ঐ পাতায় → anon public |
| `SUPABASE_SERVICE_ROLE_KEY` | ঐ পাতায় → service_role ⚠️ গোপন |
| `ADMIN_JWT_SECRET` | নিচের কমান্ডে বানান |

```bash
openssl rand -base64 32
```

> 🔴 `.env.local`-এর সিক্রেটটা লাইভে দেবেন না। ওটা ডেভেলপমেন্টে ঘুরেছে,
> লিক হলে যে কেউ অ্যাডমিন সেশন বানিয়ে ফেলতে পারবে।

env বসানোর পর একবার **Redeploy** করতে হবে (Vercel নতুন env নিয়ে আবার
বিল্ড করে)।

**✅ দেখার কথা:** `https://<your>.vercel.app` খুললে হোমপেজ আসে,
`/admin/login` খুললে লগইন পাতা।

## ধাপ ৩ — প্রথম অ্যাডমিন অ্যাকাউন্ট

পাসওয়ার্ড bcrypt হ্যাশ করে বসাতে হয়। হ্যাশ বানান:

```bash
cd nikash-web
node -e "require('bcryptjs').hash(process.argv[1],10).then(h=>console.log(h))" 'আপনার-পাসওয়ার্ড'
```

আউটপুটটা (`$2a$10$...` দিয়ে শুরু) কপি করে Supabase → SQL Editor:

```sql
insert into public.platform_admins (name, email, password_hash, role, is_active)
values (
  'আপনার নাম',
  'admin@nikash.app',          -- আপনার ইমেইল
  '$2a$10$এখানে-হ্যাশটা-বসান',
  'super_admin',
  true
);
```

লগইন করার **সাথে সাথেই** `/admin/settings` → 2FA চালু করুন।

**✅ দেখার কথা:** লগইন হয়, ড্যাশবোর্ড দেখা যায়।

## ধাপ ৪ — অ্যাপের APK

### ৪.১ `.env` বদলান

```env
EXPO_PUBLIC_API_URL=https://<your>.vercel.app
```

> ⚠️ এখন লোকাল IP বসানো আছে। না বদলালে APK-তে সাইনআপ কাজ করবে না।

### ৪.২ বিল্ড

`eas.json` তৈরি করা আছে (production · preview দুটো প্রোফাইল)।

```bash
cd nikash-app
npm i -g eas-cli
eas login
eas build:configure          # প্রথমবার — projectId বসাবে
eas build --platform android --profile production
```

বিল্ড শেষে EAS একটা ডাউনলোড লিংক দেবে।

### ৪.৩ APK লিংক বসান

অ্যাডমিন প্যানেল → **সেটিংস → অ্যাপ লিংক** → `apk_url`-এ লিংকটা।
ডাউনলোড পেজে (`/download`) সাথে সাথে দেখাবে।

## ধাপ ৫ — ভার্সন রেজিস্টার করুন (নতুন)

অ্যাডমিন প্যানেল → **অ্যাপ ভার্সন** → নতুন ভার্সন:

| ঘর | প্রথম রিলিজে |
|---|---|
| version | `1.0.0` |
| build_number | `1` |
| apk_url | EAS-এর লিংক |
| force_update | ❌ বন্ধ |
| min_supported | `1.0.0` |

**এটা কেন জরুরি:** APK Play Store-এ নেই, তাই নিজে থেকে আপডেট হয় না।
এই টেবিলেই অ্যাপ দেখে নতুন ভার্সন এসেছে কিনা।

### পরে যখন আপডেট দেবেন

1. `app.json`-এ `version` বাড়ান (`1.0.1`)
2. `eas build` চালান
3. অ্যাডমিন প্যানেলে নতুন সারি যোগ করুন, `build_number` বাড়িয়ে
4. জরুরি বাগ হলে **force_update চালু** করুন — পুরনো ভার্সনের সবার
   পর্দা আটকে যাবে, আপডেট না করে এগোতে পারবে না
